# 📝 便签与任务

PC 桌面端便签 + 任务进度管理应用，支持封面密码锁、到点提醒与 WebDAV 云备份。

## 启动

```bash
npm start
```

首次使用需已安装依赖：`npm install`（已配置国内镜像）。

## 功能

### 🔒 封面密码锁（v1.1 新增）
- 启动先显示「书本封面」，输入密码后封面 3D 翻页打开进入主界面
- 首次使用可设置密码或跳过；之后在「设置 → 密码保护」中开启/修改/关闭
- 关闭窗口驻留托盘后再次打开会自动重新锁定；顶栏 🔒 可一键锁定
- 密码在本机 scrypt 加密存储；连续输错 5 次将暂停尝试 10 秒
- 未解锁时数据不加载进界面，锁定状态下的到点提醒不显示任务内容

### 📝 便签
- 五彩便签（黄/粉/蓝/绿/紫），鼠标悬停点 🎨 可换色
- 点击即编辑，自动保存；`Ctrl+N` 快速新建
- **🗑 撕掉**：撕纸动画后移入回收站，可恢复或彻底删除
- **📄 存入文档**：选择分类归档到「归档库」，可整体导出为 Markdown / TXT

### 📦 归档库分类（v1.1 新增）
- 归档时可选四个细项：🔐 密码箱 / 💻 技术笔记 / 📋 工作纪要 / 🏡 日常记录
- 归档库弹窗按分类筛选、显示分类徽标，导出文件按分类分组

### ✅ 任务进度
- 「待办 / 已完成」两组，勾选即完成，完成后**文字划线 + 变灰**
- 顶部进度环显示总完成率、待办数、已完成数、今日完成数
- 任务支持优先级（🔴高/🟡中/⚪无，高优先级靠前）、截止**日期+时间**、子任务进度条
- **⏰ 到点提醒（v1.1 新增）**：待办到截止时间弹出系统通知（带声音），点击通知定位并高亮该任务；应用驻留托盘时也能提醒；修改截止时间自动重新计时；应用未运行期间早已过期的任务不补发
- 点任务右侧「⋯」展开详情编辑；子任务在详情里添加

### 🚀 开机启动（v1.1 新增）
- 设置 → 通用 → 开机自动启动：写入系统启动项，启动后静默驻留托盘

### ☁️ 云备份
- **WebDAV**（坚果云 / Nextcloud / Alist 等）：设置面板填地址、账号、应用密码，可测试连接、一键备份/恢复、自动定时备份（1/6/24 小时）
- **手动导出**：全部数据导出 JSON 文件 / 从 JSON 恢复
- 密码使用系统级加密（safeStorage）保存在本机

### 其他
- 系统托盘常驻：右键可快速新建便签/任务
- 深色模式（右上角 🌙）
- 全局搜索、便签/任务实时过滤
- 关闭窗口后驻留托盘，从托盘菜单退出

## 坚果云 WebDAV 配置示例

1. 注册/登录坚果云 → 账户信息 → 安全选项 → 添加「应用密码」
2. 本应用设置中填：
   - 服务器：`https://dav.jianguanyun.com/dav/`
   - 账号：注册邮箱
   - 应用密码：第 1 步生成的密码

## 数据位置

本地数据保存在 `%APPDATA%/sticky-notes-tasks/`（data.json 为全部内容，config.json 为配置）。
